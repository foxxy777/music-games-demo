# 随机3音出题版本（存档）

> 📦 本文件夹是 git tag `initial-v1-2026-08-24` 的完整快照，2026-08-30 20:27 花火大爷吩咐存档。

## 这是什么版本

- **V10b 首个试玩通过版**（2026-08-24 打 tag）
- 玩法：随机出 3/4/5 个音（开局可选难度，默认 3 音），听音辨序，按顺序点琴键复刻
- 出题范围：27 音全音域（3G~5A，含所有升号）随机抽，避免相邻重复
- 布局：左列竖排 27 个琴键（5A 顶 → 3G 底）+ 右侧主区
- 音频：54 个人声素材（27 出题音 + 27 答题音，X Studio 人声，YIN 验证过）

## 与当前版的区别

当前线上版（2026-08-30 起）：题目 = 小星星整曲（14 音），五线谱谱面跟谱高亮，底部 12 键横排，无难度选择。
本版：随机短序列出题、竖排 27 键、有难度选择、无谱面。
